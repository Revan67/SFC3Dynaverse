"SFCTNG Base Class List.  These ships are the basis on which all ships are created from.  Each one should have a unique model.  This data represents the aspects of the ship that can not be modified in game. They are the foundations of the ship class itself.  For instance any particular galaxy class ship can not hold more weapons, power, or hull spaces than defined in here.  They also can not be any lighter than the minimum weight."																			
Explanations																			
POLITICALBASE: This is the empire or organization that fields this ship.																			
SizeClass: The sizeclass is the general size of the ship.  This governs it odds for begin hit by enemy fire.  Note this number is subjective and not a strict interitation of actual size.  Some ships MAY have sizeclasses that are less than the sizeclass of a similar sized ship.  This allows the ship designer to have more control in designing a ship.  For instance MAYBE a ship is considered to be experimental and it has a built in stealth material. OR that the material is particularly easy to detect with sensors.																			
"Class: SH,PF,F,FF,DD,DW,CL,CA,NCA,BCH,CV,DN,BB,LP,BS,BT,SB,BIO,PLANET,SPECIAL"																			
"BaseWeight: Since the max impulse speed is determined by Mass vs. Thrust, the Raw weight of a ship before any weapons, hull additions or power plants are added.  This will enforce the concept that larger ships weigh more than small ships and thus will have lesser acceleration even if equipped with the same loadout"																			
"PowerPlantSpace,WeaponSpace, and Hull Space:  This is the amount of mass (room) that the ship will accept within these categories.  The more space a ship has the more items the ship can hold"																			
ModelName:This is the name of the model and UI that will be used to represent the ship																			
AlternateModelName: this is used if the first choice (Modelname) is not found.  This will allow players to add ships to the game that use new models and also provide a substitute for people how did not download that model.
